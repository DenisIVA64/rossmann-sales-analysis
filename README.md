# Rossmann: анализ продаж сети магазинов (2013–2015)

Анализ ежедневных продаж 1 115 магазинов Rossmann: сезонность, влияние числа работающих магазинов, эффективность промо-акций и ABC-анализ. Проект отвечает на практические вопросы, которые обычно ставит аналитику розничная сеть.

**Инструменты:** Python (pandas, matplotlib), SQL (SQLite: CTE, оконные функции, CASE).

## Данные
[Rossmann Store Sales (Kaggle)](https://www.kaggle.com/c/rossmann-store-sales/data):
- `train.csv`: 1 017 209 строк, ежедневные продажи с 2013-01-01 по 2015-07-31;
- `store.csv`: справочник 1 115 магазинов (тип, ассортимент, конкуренты, промо).

В репозиторий данные не входят: скачайте их с Kaggle и положите рядом с ноутбуком. Сводные таблицы с результатами лежат в папке `results/`.

## Основные выводы
1. **Сезонность.** В оба года декабрь самый сильный месяц по средним продажам на магазин (около 8 600 в день).
2. **Спад выручки в 2014.** С июля по декабрь 2014 в данных 934 магазина вместо 1 115. Все 181 пропавший магазин вернулись к марту 2015, поэтому спад суммарной выручки объясняется числом магазинов, а не падением спроса в магазине. Причина отсутствия (по описанию датасета, временное закрытие) самими данными не подтверждена.
3. **Промо.** В дни с промо средние продажи магазина выше на 38,8% (8 229 против 5 930). Прирост сохраняется в каждый будний день (от 22,1% в пятницу до 57,0% в понедельник) и почти во всех магазинах (1 114 из 1 115). В разрезе типов магазинов (только будни): +42,2% у типа d, +39,5% у c, +37,7% у a и +20,0% у b.
4. **ABC-анализ по суммарной выручке.** 775 магазинов (70% сети) формируют 80% выручки, 235 (21%) ещё 15%, 105 (9%) оставшиеся 5%. Выручка распределена по сети ровно. Часть класса C (43 из 105 магазинов) составляют магазины, которые 8 месяцев отсутствовали в данных, поэтому их выручка занижена.

## Ход анализа
1. Знакомство с данными и очистка: оставлены дни, когда магазин был открыт и были продажи (844 338 строк из 1 017 209).
2. Динамика выручки и средних продаж на магазин по месяцам.
3. Проверка причины спада 2014: число работающих магазинов по месяцам и возвращение пропавших.
4. Оценка промо: общее сравнение, по дням недели, по каждому магазину.
5. SQL: ABC-анализ (оконная функция `SUM() OVER`) и прирост от промо по типам магазинов.

## Ограничения
- Связь промо с продажами не доказывает причину: акции назначаются не случайно.
- Причина отсутствия 181 магазина в данных не подтверждена.
- В анализе не использованы погода, праздники, конкуренция и участие в Promo2.
